# MindTo3D Website

Mở `index.html` để xem website.

## Chỗ cần thay thông tin
Trong `index.html`, tìm:
- `YOUR_ZALO_ID` → ID/link Zalo của bạn
- `YOUR_PAGE` → link Facebook
- `YOUR_EMAIL@gmail.com` → email nhận đơn

Logo hiện tại nằm ở `assets/logo.jpg`.

Website là landing/storefront responsive, gồm:
- Hero / giới thiệu MindTo3D
- Sản phẩm
- Dịch vụ
- Quy trình
- 3 nút liên hệ duy nhất: Zalo, Facebook, Email
